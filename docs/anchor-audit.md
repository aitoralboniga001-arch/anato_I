# Leader-dot audit

Generated by `node scripts/anchor-audit.mjs` (needs `npm run dev`; checks `/dev/frames?anchors=1&w=N`).

Rule: a name's dot must sit well inside the structure it names, at least 4 frame units from any edge with
another structure. The dot and 8 points on a 4-unit ring around it must all land on that structure (or a
drawing inside it). Every view of every stage is checked at each step's finished frame. Each row: view ·
steps · name · dot position · probes off (of 9) · what the off probes land on (`(hondoa)` = background).
**Dot off** means the dot itself is not on its structure.

Total: 1275 name placements.
